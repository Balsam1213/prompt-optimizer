## 六层约束模型

提示词失控，几乎总能归因到某一层约束缺失。写稿前过一遍，出稿后用它自检：

```
L1 事实 → L2 媒介 → L3 结构 → L4 一致性 → L5 排除 → L6 参数
 不编造    定边界    排顺序     锁变量      划红线    剥离元数据
```

| 层 | 一句话约束 | 典型失误 |
|---|---|---|
| **L1 事实** | 不编造焦距、光圈、型号、品牌、IP、地点；不确定就描述可见的视觉结果 | 写 `85mm f/1.4` 但画面毫无依据 |
| **L2 媒介** | 明确目标媒介，并排除最容易混淆的错误媒介 | 想要写实却出了插画感 |
| **L3 结构** | 3—5 个核心锚点写进正文前 1/3，维度按序不堆砌 | 十二个维度各写一句，画面糊成一团 |
| **L4 一致性** | 需要跨图跨镜稳定的元素，显式声明为不变量 | 第二张图换脸、换服装 |
| **L5 排除** | 排除项具象化、有针对性，不写抽象「no X」 | `no man-made structures` 完全无效 |
| **L6 参数** | 模型名/时长/比例/分辨率外置到「推荐参数」行 | `--ar 16:9` 混进给 Gemini 的正文 |

### L1 事实层——不编造

只描述能看到、能推断、能负责的内容：

- 焦距、光圈、机身镜头型号：仅当用户给了元数据或画面证据足够明确才写，否则转写为视觉效果。`85mm f/1.4` → `中长焦人像压缩感，浅景深，背景柔和虚化`。
- 品牌 / IP / 角色名 / 地点：内部分析可以理解，**输出默认不依赖专名**，转写为外形、配色、服装、轮廓、材质、设计语言。
- 看不清的东西不补全：说「模糊标识」「简化图案」。
- `8K`、`超高细节` 只能作为**期望生成质量**写，不声称是原图真实参数。

自检：提示词里每个具体数字和专有名词，我能指出依据吗？指不出来的删掉。

### L2 媒介层——定义边界

先判定媒介再动笔，并在排除项里显式排除最容易混淆的错误媒介：

| 媒介 | 必须排除的混淆项 |
|---|---|
| 摄影 | 3D 渲染感、插画感、过度磨皮 |
| 写实 3D | 真人摄影、二次元、厚涂 |
| 二次元插画 | 写实摄影、复杂 3D 体积 |
| 厚涂插画 | 摄影、矢量扁平 |
| 扁平矢量 | 写实摄影、真实材质 |
| 产品渲染 | 生活随拍、杂乱背景、低质反射 |
| UI / 平面设计 | 摄影景深、无意义装饰 |

混合媒介只有一种占主导，按主导者写；判定不明时选最接近用户意图的，交付时说明「按 X 处理」。

自检：把提示词给不知道上下文的人看，他能说出这是摄影还是插画吗？

### L3 结构层——排顺序

正向提示词的组织顺序（生图）：

```
[主体+关键特征] → [3—5 个视觉锚点] → [动作/姿态] → [场景/环境] → [构图+镜头]
→ [光线] → [色彩] → [材质] → [空间层次] → [情绪] → [风格] → [后期/画质]
```

锚点优先级（挑 3—5 个放前 1/3）：①独特构图/画面结构 ②主体轮廓、姿态、比例 ③特殊镜头关系（视角、透视、遮挡）④标志性光线 ⑤关键材质 ⑥背景几何 ⑦色彩关系。

反模式：把所有维度塞满、每条写一点 → 模型注意力被稀释，命中率反而下降。**宁可五个维度写透，不要十二个维度写平。**

自检：删掉后半段，画面还成立吗？

### L4 一致性 / L5 排除

完整方法见 `gen-consistency-negative.md`。速查：需要锁的（脸、服装、光线方向、色调、风格）显式声明为不变量；排除项具象化、有针对性、分层组织。

### L6 参数层——剥离元数据

生成控制参数与正文分离，外置成一行：

```
推荐参数：比例 16:9 ｜ 时长 10s ｜ 分辨率 2K ｜ 9:16 竖版
```

正文里**不出现**：模型名、版本号、时长、比例、分辨率、CFG、seed。例外：目标模型官方 schema 本身要求这些字段时（MiniMax 的字段名、Seedance 多镜头时间轴），按官方格式保留。

自检：把提示词粘进模型输入框，里面每个词都是给**画面**的指令吗？混进去的「给工具的指令」剥离出来。

## 双语输出契约（生成类）

- **中文版给用户理解和校对，`English:` 版给模型执行。** 英文用图像/视频模型惯用表达，不做机械直译。
- 用户点名中文友好模型（即梦、可灵等）或只要单语时按用户；否则生成类默认双语对照。
- 成品放代码块，单段自然语言（目标模型要求结构化多行时除外），不是散落的关键词碎片。
- 默认只出成品，不倒分析过程；给选项时给 2—3 个**各自自洽完整**的变体，不出半成品拼盘；收尾最多一句「可调项」。

## 复杂度分级

先判断用户要什么，再决定输出形态，不把所有输入都套复杂模板：

- **Level 1 极简版**：`[主体]，[核心风格]，[场景/构图]，[光影或氛围]，[质量收尾]` —— 用户要简单、快速试稿时。例：`雨夜霓虹巷中的赛博少女，电影感打光，高细节人像，浅景深`
- **Level 2 平衡版（默认）**：主体+特征、环境、动作/姿态、构图/镜头、光影、色彩、风格、质量。
- **Level 3 结构化版**：主体 / 场景 / 构图 / 光影 / 色彩 / 风格 / 细节 / 质量 / 排除 分行 —— 商业级、可复用、变量填充场景。

用户没表态默认平衡版；明确说「只要一句 / 简单点」就只出极简版 + 一条简短建议。

## 交付前自检（生成类）

- [ ] 意图保真：补的是维度，没把主题换掉
- [ ] L1 每个数字/专名有依据；L2 媒介明确且排除了混淆媒介；L3 锚点前置、维度不堆砌；L4 不变量已声明；L5 排除具象、有针对性；L6 参数外置
- [ ] 双语对照齐全（或按用户要求单语）
- [ ] 成品在代码块里可整块复制；负面词 8—15 条且与正面描述无冲突
- [ ] 抽象词（高级感、电影感）都用了具体视觉元素解释
- [ ] 结尾一句可调项，没有长篇解释和客套
