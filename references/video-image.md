# 图像 / 视频生成提示词 Playbook

图像和视频生成类提示词与其他类型有本质区别：**它描述的是画面本身，而不是给 AI 下达任务**。不写"请画一只猫"，而是直接写"一只橘猫蜷在雨后的红瓦屋顶上……"。这是本 playbook 与 frameworks.md 的最大差异，其余交付流程（假设、可选确认、固定交付格式）仍然遵循 SKILL.md。

## 图像：七要素

按此顺序写，重要的放前面（模型对提示词前段权重更高）：

1. **主体**：是什么 + 外观细节（数量、颜色、材质、状态）
2. **动作/姿态**：主体正在做什么
3. **场景环境**：在哪里 + 环境细节
4. **风格/媒介**：摄影 / 水彩 / 3D 渲染 / 扁平插画 / 胶片……
5. **构图与镜头**：景别（特写/中景/远景）+ 视角（俯拍/仰拍/平视）+ 焦段感（广角/长焦虚化）
6. **光线**：时段 + 光质（柔和晨光 / 硬朗正午光 / 霓虹逆光）
7. **色彩氛围**：主色调 + 情绪

模板：

```
{{主体+细节}}，{{动作}}，{{场景环境}}，{{风格/媒介}}，{{构图与镜头}}，{{光线}}，{{色彩氛围}}
```

把「一只猫在屋顶」补全成成品：

```
一只橘色虎斑猫弓着背蹲坐，正低头注视下方，雨后的老城区红瓦屋顶，水彩插画风格，中景、略俯视视角，清晨柔和的散射光，瓦片上残留水洼泛着淡蓝，整体氛围安静清新
```

支持负面提示词的工具（如 Stable Diffusion）可在末尾加一行：`负面：低画质、变形、多余肢体、水印`；不支持的（如 Midjourney 用 `--no` 参数）按工具语法处理。

## 视频：在七要素之上加运动

视频提示词 = 画面要素 + **随时间的变化**。额外四项：

1. **镜头语言**：开头先写景别和运镜
2. **主体动作**：动作过程要连续可想象，用"缓慢抬起头""转身走向镜头"这类动词，不写"很酷的动作"
3. **时长与节奏**：多少秒、快慢感受
4. **时间线**（工具支持时）：用"0–2 秒……，2–5 秒……"分段

模板：

```
{{景别}}，{{运镜}}。{{主体及外观}}正在{{连续动作}}，{{场景环境}}，{{风格与氛围}}，{{光线与时段}}。时长 {{N}} 秒，节奏{{舒缓/紧凑}}。
```

### 运镜词汇表

| 汉语 | 效果 |
|---|---|
| 推（推进）| 镜头靠近主体，聚焦感 |
| 拉（拉远）| 镜头远离，展示全貌 |
| 摇 | 镜头原地左右/上下转动 |
| 移 / 跟随 | 镜头平行移动，跟拍主体 |
| 环绕 | 围绕主体 360° 或弧线旋转 |
| 俯拍 / 仰拍 | 从上往下 / 从下往上看 |
| 手持 | 轻微晃动，纪实感 |
| 固定机位 | 镜头不动，画面内的元素在动 |

### 关键规则

- **一个提示词一个连续镜头。** 多镜头叙事拆成多条提示词（或一个分镜列表，每条独立可投喂），不要把切换写进单条提示词——多数模型处理不好"然后镜头一切"。
- 动作优先写**主体运动**，其次才是镜头运动；两者都写时避免方向矛盾。
- 时长适配目标工具的档位（常见 5s / 10s），不确定就在「可选确认」里问或按 5 秒假设。

### 完整示例：一句话需求 → 成品

用户说：「帮我写个视频 prompt，赛博朋克城市夜景」→ 成品：

```
低角度仰拍，镜头缓慢向前推进。雨夜的未来都市街道，两侧摩天楼外墙布满巨型全息广告与霓虹招牌，粉紫与青蓝的霓虹在湿漉漉的路面拉出倒影。一个穿黑色长风衣的身影背对镜头，撑着透明伞缓缓走入光雾深处。电影感实拍质感，浅景深，霓虹逆光勾勒轮廓，空气中飘着细雨与薄雾。时长 5 秒，节奏舒缓。
```

关键假设：未指定时长（按主流 5 秒）、实拍电影感而非动画风格、单镜头无叙事。这些写进交付的「关键假设」一节。

## 主流工具差异

要素化写法是通用的，用户指明工具时按此微调：

| 工具 | 写法偏好 |
|---|---|
| Sora / Veo | 自然语言长句 + 叙事性描述，允许写声音和氛围 |
| 可灵 / 即梦 | 主体+动作+场景+风格的要素短句，顺序重要 |
| Midjourney（图像）| 短语堆叠 + 参数后缀（`--ar 16:9`、`--v`、`--style`）|
| Stable Diffusion | 逗号分隔标签 + 独立 negative prompt |

用户没指明工具时，按"自然语言长句"写（对多数新工具兼容），并在「可选确认」里问一句目标工具。
