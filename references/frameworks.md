# 提示词结构框架库

SKILL.md 第 3 步的展开：每个框架的适用场景、写法和中文示例片段。选框架时先看文末的「按任务类型选择」决策表。

## 基座骨架（所有类型通用）

```
你是{{角色，含专业背景}}。

## 任务
{{一句祈使句说清要产出什么}}

## 上下文
{{用户提供的背景、素材、现状——写具体事实}}

## 约束
- {{可验收的约束 1}}
- {{可验收的约束 2}}

## 输出格式
{{字面模板或示例}}

## 质量标准
{{合格产出的判断标准}}
```

六段不是每段都必须，但**角色、任务、输出格式**三段几乎不可省略。素材很长的场景（如贴了一篇文档让 AI 分析），上下文放在任务之后、用分隔符包起来，避免 AI 把素材当指令。

## 可叠加组件

### 思维链引导

写法：在输出格式之前加一步，如"先逐项列出各方案的优缺点，比较后再给出最终推荐"。

适用：多方案比较、复杂决策、需要多步推理的任务。不适用于简单事实检索（会拖慢且无收益）。

示例片段：

```
先分别分析三个方案的实现成本、维护难度和性能，逐项对比后再给出最终推荐。分析过程写入「分析」一节，结论写入「结论」一节，不要混在一起。
```

### Few-shot 示例

写法：给 1–3 组「输入 → 期望输出」的完整例子，放在输出格式之后。

适用：输出格式难以用文字描述清楚、需要模仿特定文风或语气、分类标准主观的场景。

示例片段：

```
按下面的例子输出：

输入：今天天气真好
输出：😀 晴天 | 情绪：积极 | 置信度：0.9

输入：又被甲方改需求了
输出：😡 吐槽 | 情绪：烦躁 | 置信度：0.8
```

### 输出模板锁定

写法：给一个字面的填空模板，执行 AI 只能往里填内容、不能改结构。

适用：要产出固定结构（表格、JSON、固定段落）的场景；也用于需要批量一致性的任务。

示例片段：

```
每份周报严格按此模板输出，不要增删章节：

## 本周完成
- {{事项}}（{{状态：已完成/进行中}}）
## 下周计划
- {{事项}}
## 风险与需要的支持
- {{风险}}：{{需要的支持}}
```

### 自检清单

写法：在提示词末尾加"输出前先自查以下各项，任何一项不满足就先修正再输出"，逐条列出检查点。

适用：代码、数据计算、事实引用等容易出错的任务；清单应是可判定的（"所有变量都有声明"而非"代码质量要好"）。

示例片段：

```
输出前自查，任何一项不满足就先修正再给出最终答案：
- 所有输入数据都已用到，没有遗漏字段
- 每个结论都能在上文数据中找到依据
- 代码可直接运行，无伪代码
```

### 允许追问

写法：明确授权执行 AI 在信息不足时反问，并规定"最多问 N 个问题、一次问完"。

适用：任务本身就是多轮协作（教练、面试官、需求访谈类提示词）。注意与"自包含"原则的关系——一次性产出类任务不要用这个组件，直接做假设。

## 按任务类型选择

| 任务类型 | 骨架侧重 | 叠加组件 |
|---|---|---|
| 编码 | 上下文（技术栈、运行环境、相关代码）+ 边界条件 | 自检清单、输出模板 |
| 写作 | 受众 + 文风约束 + 长度 | Few-shot（文风模仿）、输出模板 |
| 分析/决策 | 输入数据 + 分析维度 | 思维链、输出模板 |
| 图像/视频生成 | 见 `video-image.md`，骨架不适用 | — |
| Agent 系统提示词 | 角色 + 能力边界 + 工作流程 + 异常处理 | 自检清单、允许追问 |
| 翻译/改写 | 术语表 + 风格约束 + 原文占位符 | 输出模板 |

### 编码类示例（一句话需求 → 成品）

用户说：「帮我写个提示词，让 AI 帮我写爬虫」→ 成品：

```
你是资深 Python 后端工程师，擅长数据采集与反爬处理。

## 任务
编写一个 Python 脚本，抓取 {{目标网站 URL}} 的 {{目标数据，如：商品标题、价格}}，保存为 CSV。

## 上下文
- 运行环境：{{如：Python 3.11，Windows}}
- 页面结构：{{如有 HTML 片段或接口示例，贴在这里；没有就写"未知，脚本需先探测页面结构"}}
- 频率要求：{{如：每页间隔 2–3 秒随机延迟；不确定就删掉此条}}

## 约束
- 只用 requests + BeautifulSoup，不引入重型框架
- 处理请求失败：重试 3 次、指数退避
- 目标数据字段缺失时跳过该条并记录日志，不中断整体抓取

## 输出格式
单个完整脚本文件，代码中的关键逻辑加注释，最后附一段 50 字以内的使用说明。

## 质量标准
脚本在我的环境中直接运行即可出结果，无需修改；不含硬编码的密钥或本地路径。
```

### Agent 系统提示词示例（骨架侧重）

```
你是 {{产品名}} 的智能客服，负责回答用户关于 {{业务范围}} 的问题。

## 能力边界
- 只回答 {{业务范围}} 相关问题；无关请求一律回复固定话术："抱歉，我只能解答 XX 相关问题"
- 不知道的信息明确说"我不确定"，禁止编造价格、政策、承诺

## 工作流程
1. 识别用户问题类型：咨询 / 投诉 / 操作指导
2. 咨询类：基于下方知识库回答，引用具体条款
3. 投诉类：先共情回应，再引导用户提供订单号，记录到 {{工单字段}}
4. 操作指导类：分步骤说明，每步一个动作

## 输出格式
不超过 150 字的口语化中文，不用列表符号，一次只解决一个问题。

## 知识库
{{粘贴知识库内容}}
```
